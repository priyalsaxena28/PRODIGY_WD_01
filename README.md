# PRODIGY_WD_01 – Interactive Navigation Menu

## 📖 Overview

This project was developed as part of the **Prodigy InfoTech Web Development Internship**. It implements a responsive and interactive navigation menu using **HTML5, CSS3, and JavaScript**. The navigation bar remains fixed at the top of the page and dynamically responds to user interactions, providing an intuitive and seamless browsing experience.

The project demonstrates fundamental frontend development concepts, including responsive web design, DOM manipulation, event handling, and interactive UI development while maintaining clean, modular, and maintainable code.

---

## ✨ Features

- Responsive Navigation Menu
- Fixed Navigation Bar
- Scroll-Based Styling Effects
- Interactive Hover Effects
- Section-Based Navigation
- Clean and User-Friendly Interface
- Cross-Browser Compatibility
